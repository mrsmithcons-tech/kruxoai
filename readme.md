## 📦 Download & Getting Started

### Option A: Pre-Compiled Standalone Release (Recommended)
1. Download the latest `KruxoAI-Setup.exe` from [GitHub Releases](https://github.com/mrsmithcons-tech/kruxoai/releases).
2. Run the installer and launch **KruxoAI**.
3. Activate with your $20 Lifetime License Key from [kruxoai.com](https://kruxoai.com).

### Option B: Run from Source (Developers)

```bash
# 1. Clone the repository
git clone https://github.com/mrsmithcons-tech/kruxoai.git
cd kruxoai

# 2. Create virtual environment
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Setup API Keys
cp config/api_keys.example.json config/api_keys.json
# Edit config/api_keys.json with your Gemini API key (free at aistudio.google.com)

# 5. Launch KruxoAI
python main.py
```
